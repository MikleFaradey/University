Результаты тестирования плохих запросов
============================================================

1. Несуществующий пользователь
Код ответа: 404
Ответ: {"error": "Пользователь не найден"}

2. Несуществующий маршрут
Код ответа: 404
Ответ: {"error": "Маршрут не найден"}

3. POST без тела
Код ответа: 400
Ответ: {"error": "Тело запроса пустое"}

4. Невалидный JSON
Код ответа: 400
Ответ: {"error": "Невалидный JSON"}

5. Неверный тип поля score
Код ответа: 400
Ответ: {"error": "Поле score должно быть неотрицательным целым числом"}

6. Неподходящий HTTP-метод
Код ответа: 405
Ответ: {"error": "Метод не поддерживается"}

7. Внутренняя ошибка сервера
Код ответа: 500
Ответ: {"error": "Внутренняя ошибка сервера"}

8. Обрыв соединения посреди отправки
Код ответа: соединение разорвано клиентом
Ответ: см. server.log

Контрольный запрос после всех ошибок
Код ответа: 200
Ответ: {"user1": {"name": "Алексей", "game": "Dota 2", "level": 42, "score": 15820, "playtime_hours": 210}, "user2": {"name": "Мария", "game": "Valorant", "level": 30, "score": 9870, "playtime_hours": 95}, "user3": {"name": "Игорь", "game": "CS2", "level": 55, "score": 21000, "playtime_hours": 340}}

После всех ошибок и обрыва соединения выполнен контрольный GET /users.
Если он вернул 200 OK, сервер продолжил работу и не завершился аварийно.
