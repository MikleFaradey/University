# Скриншоты работы программы

В этом каталоге должны размещаться реальные снимки экрана консольного приложения для отчёта и защиты. Для получения снимков запустите `python -m host.main` или `python scripts/run_demo.py`, затем сохраните изображения экрана. Ниже приложен подлинный текст вывода автоматического демонстрационного запуска в `demo_cli.txt`. Он не заменяет скриншоты.
