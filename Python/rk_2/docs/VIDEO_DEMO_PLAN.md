# Последовательность проверки интерфейса CVE Analytics

В процессе проверки зафиксированы экран входа, форма регистрации, аналитическая панель с четырьмя KPI, четыре визуализации, таблица с поиском и экспортом CSV, настройки фильтрации и изменение расчётных показателей после сохранения параметров. Результаты представлены в [отчёте о запуске и проверке](../ОТЧЕТ_ЗАЩИТА.md).
