# Сценарий видеодемонстрации РК-2

Сначала запустить приложение через `streamlit run app.py`. Затем записать экран с регистрацией, входом, открытием всех трёх функциональных страниц, сохранением фильтров, изменением KPI и четырёх графиков, поиском, экспортом CSV и повторным входом. Видео необходимо записать самостоятельно в работающем интерфейсе; готового видео в данном репозитории нет.
