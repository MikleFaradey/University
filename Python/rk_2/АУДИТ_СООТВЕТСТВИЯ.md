## Открытые действия перед сдачей

1. На Mac: `python -m pip install -r requirements.txt pytest`.
2. `python fetch_datasets.py` и `python scripts_check.py --strict --check-reference`; ожидается `Итог: OK` и всего 15 847 записей.
3. `python -m pytest -v`: не должно быть `FAILED` или `SKIPPED` (Streamlit установлен).
4. `python -m streamlit run app.py`: вручную проверить вход, выход, сохранение фильтров, четыре графика и экспорт.
5. Опубликовать репозиторий, записать видео и приложить Markdown-отчёт.

Промышленная безопасность (HTTPS, rate limiting, распределённая доставка, резервирование) в учебном задании **не требуется** и здесь не заявляется.
